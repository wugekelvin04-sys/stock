# Stock Desk

个人持仓与期权桌面应用,由 Claude Code 驱动 AI 分析。

## 功能(规划)

- 截图 / PDF 导入持仓与期权(走 Claude vision)
- 持仓与期权趋势行情(免费数据源聚合,5 分钟刷新)
- 一键 AI 分析:涨跌归因、买卖理由、利好利空、期权仓位建议
- 任意股票搜索(`⌘K`)
- 主界面三榜单:涨幅 / 跌幅 / 每日 AI 机会榜
- 开盘期间整点持仓 insight

## 全局快捷键

| 快捷键 | 作用 |
|---|---|
| `⌘⌥\` | 显示 / 隐藏主窗口(全局) |
| `⌘K` | 应用内股票搜索(规划中) |
| `⌘Q` | 退出 |

## 开发

```bash
npm install
npm run dev
```

依赖:Node 20+、`claude` CLI 已登录。
